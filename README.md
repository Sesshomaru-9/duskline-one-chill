## The entry

> The photograph from my grandmother's funeral shows a boy my age standing behind the mourners, smiling at the camera — and he has my face.

137 characters. A photograph, a funeral, a boy the narrator's own age
smiling at the camera — and he has the narrator's face. The scare is
earned, not announced: the reader does the maths. No mirror, no doll, no
basement, no gore — just an impossible face in an old photograph, and the
dread of what it means.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13 standard library only) validates the line with
`_validate_entry` (1–200 characters, one sentence, one line, no carriage
returns or control characters) and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then reads it back
and re-validates what is on disk. It refuses with exit 1 if the output
directory is inside this repository, since the grader sandbox mounts the
repo read-only.
